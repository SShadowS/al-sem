# census-probe

Counting-allocator byte census of the LSP snapshots, one DepCache shared across roots; `--with-updaters` also starts each root's real updater and measures the idle heap. Accounting conventions (the local, untracked skill `.claude/skills/byte-census/SKILL.md` has the long form): a counting `#[global_allocator]` over `System` is the only size evidence; bytes are requested heap size, allocator overhead excluded; MiB = 1,048,576 B; "retained" = live heap once it stops moving for 0.9 s; "peak" = highest live heap during a build; OS RSS is context only, never a result. The probe is deliberately tracked under `tools/` (it is a measurement tool, not CI), and its own `[workspace]` table keeps it out of the repo workspace.

Build: `CARGO_TARGET_DIR=C:/lpt cargo build --release` here (own workspace; never build into the repo's `target/`). Run: `C:/lpt/release/census-probe.exe <embedded|symbols> <root>... [--with-updaters]`.

No gate compiles the probe, so it breaks silently when the crate's API moves. Before each step's re-run, check it first: `CARGO_TARGET_DIR=C:/lpt cargo check --manifest-path tools/census-probe/Cargo.toml` (from the repo root).

Corpora: CG harness = roots `Core Fleet Integration Leasing Rental Reporting Test` of `U:/Git/CentralGauge/harness-tasks/refapp`, copied to a scratch dir with `.alpackages` copied from `U:/Git/CentralGauge/infra/cg-test-harness/.alpackages` (rebuild: `cp -r` the refapp dir, then `cp -r` that `.alpackages` into the copy's top level); CDO = `U:/Git/DO-cdo-baseline/Cloud` (read-only). Raw outputs of the step 0 runs: `runs/`; of the after-step-1 runs (same corpora and modes): `runs-after/` (the paths printed in them are from the machine that produced them; CG = 7 roots, 36 `.al` files; CDO at `bc3ccb18`).

`--index-split` (after the roots, e.g. `census-probe.exe embedded <root>... --index-split`): for each root, builds the three structures the idle updater holds (`ResolveIndex`, workspace object map, `DeclSurface` local part) from the root's graph, records each one's live-heap delta, then drops `ResolveIndex` field by field through `census_parts()` and records each drop. Raw output of the Task 3 runs (with `--with-updaters` runs of the same binary as a cross-check): `runs-index-split/`. Those runs used a CG copy at `scratchpad/cgref/` where step 0 used `scratchpad/refapp/`; the shape lines (objects, routines per root) are identical, so it is the same corpus.
