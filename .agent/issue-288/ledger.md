## Design

Revision 5 (revision 4 + the named-return scope fix and the per-object scan cache).

**Goal.** A site that provably never runs adds no coverage gap and no cone edge (dead code already adds no facts). A site counts as dead only where today's mark is provably sound.

**Non-goals.** Reachability itself (D2: lowerer `#if` marking, the `Error` rule, globals across `#if`, must-terminate vs may-return, d20). The db-effect solver and summaries (D1). `combined_graph::assemble`. The snapshot tree and dependency-gap reach (`snapshot_full::reach`, `compose_tree`) and the step5 BFS oracle, which still walk the unfiltered `rel.cone()` (D3). The impact_graph export.

**Changes** (`rev4/proto-rev4.diff`).
1. `src/program/model/workspace.rs`: `ModelRoutine.dead_marks_trusted` (doc: fails closed — `false` default, any constructor that cannot run the checks leaves it `false`). `has_preproc_directive(text)`; `source_clean(source, range)` (fails closed when the range does not index the source); `is_bare_error_call(cs)`; `source_dead_mark_trust(source, object, &mut object_clean, routine, call_sites, variables)`, called in `project_ir`: the routine's range must be clean; every bare `Error` call must take the Text overload (two or more arguments, or one string literal, or one identifier resolved in AL's scope order — params, then the named return `routine.return_name` / `return_type`, then locals, then unshadowed globals — whose type head is Text, Label or Code; a named return with no type or a non-Text type proves nothing); a global proof also needs the object's range clean (S14), scanned once per object into an `Option<bool>` declared before the routine loop (O26). `settle_dead_mark_trust(&mut Model)`: a trusted row stays trusted only if every bare `Error` site has a `Resolution::Builtin` edge and no other edge at `(from_ix, callsite_id)` (S15). 13 struct literals get `dead_marks_trusted: false`.

A row is untrusted when its source holds any preprocessor directive (including in a comment or string); it has an `Error` call not proven Text; it has an `Error` call that does not bind to the builtin; or its Text proof rests on a global in an object whose source holds any directive. CDO cost: 0 findings (no dead site carries a call-site-local reason); 1 of 582 workspace files has a directive. This leaves the #288 symptom in untrusted rows until D2 makes the mark sound and the gate goes away.
